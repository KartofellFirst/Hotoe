# Inatallation.md
How to setup our CLI

## requirements:
+ `Python 3.11+`
+ `pip`


## Linux/macOS:
put somewhere safe, for example: <br>
`~/bin/hotoe`

make it executable: <br>
`chmod +x ~/bin/hotoe`

add `~/bin` to path so you can hotoe <command> everywhere <br>
Or call it with `~/bin/hotoe <command>` <br>
Done.

## Windows
put it somewhere accessible: <br>
`C:/hotoe`

run with python: <br>
`python "C:/hotoe" <command>`

Or create a custom `C:/bin/hotoe` script, then -> <br>
-> make it executable -> add `C:/bin` to PATH. <br>
Now you can `hotoe <command>` everywhere. <br>
Done.
